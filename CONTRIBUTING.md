# Contributing

EZ Admin Gin is primarily a maintainer-driven personal foundation project.

The repository is public for reference, learning, and reuse, but it is not operated as a community-driven open-source framework.

## Issues

Bug reports and suggestions are welcome.

When reporting a bug, please include:

- environment
- reproduction steps
- expected behavior
- actual behavior
- related logs or screenshots

## Pull Requests

Pull requests are not guaranteed to be reviewed or accepted.

This project prioritizes stability for the maintainer's own MVP projects over community-driven feature expansion.

Please open an issue first before submitting any non-trivial change.

## Out of Scope

The following are currently out of scope:

- full automated test coverage
- large testing frameworks
- microservice refactoring
- low-code / no-code engine
- complex multi-tenant isolation
- large-scale IAM platform features
- broad community governance
