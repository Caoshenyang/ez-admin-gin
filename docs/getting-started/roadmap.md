# 路线图

`EZ Admin Gin` 当前定位是维护者自用优先的后台系统基座。它公开源码供参考和复用，但不以社区协作型框架为主要目标。

> 当前稳定版本：**v1.2.0** | 当前定位：维护者自用优先，服务 SaaS/MVP 快速开发

## 阶段规划

| 阶段 | 目标 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| 项目初始化 | 建立可运行的仓库骨架 | `server`、`admin`、`docs`、`deploy`、`scripts` 职责清晰 | 已完成 |
| 后端基础设施 | 后端具备真实项目基础能力 | 配置、日志、数据库、Redis、响应格式和健康检查可运行 | 已完成 |
| 认证与权限 | 完成后台系统核心安全能力 | 登录、JWT、角色、权限、Casbin 控制链路可人工验证 | 已完成 |
| 通用系统模块 | 补齐后台底座常用能力 | 用户、角色、菜单、配置、文件、日志可管理 | 已完成 |
| 前端管理台 | 让系统可视化可操作 | 登录页、布局、动态菜单和基础管理页面可使用 | 已完成 |
| 业务模块规范 | 定义以后小项目如何接入 | 有清晰模块结构和权限接入约定 | 已完成 |
| 部署与复用 | 支持快速上线和复制 | Docker Compose、Nginx、初始化数据和部署文档齐备 | 已完成 |

## 当前状态

项目已进入轻量维护阶段，重点是让维护者能基于这套底座快速创建自己的 MVP 项目。当前文档以 `server/internal/modules/`、`admin/src/modules/`、`deploy/` 和 `scripts/` 的真实代码为准。

### 已完成

- `bootstrap / platform / modules` 后端骨架已定稿
- Auth、IAM、System、Setup 模块边界已稳定
- 用户、角色、菜单、部门、岗位、配置、字典、文件、附件、日志、公告、消息、邮件、通知等后台底座能力已就绪
- 文档体系已收口为：快速开始、架构设计、后端、前端、部署、参考手册
- 部署文档覆盖服务器二进制部署、Docker 部署、域名 HTTPS、更新回滚、生产检查清单
- 质量策略已收敛为轻量验证 + 人工测试清单

### 下一步

- 保持基础模块稳定，优先支撑维护者自己的 MVP 项目
- 继续完善人工测试清单和复用前检查
- 按真实项目需要补少量高复用业务模块

### 暂不计划

- 微服务重构
- 低代码 / 无代码引擎
- 复杂多租户隔离
- 大型 IAM 平台能力
- 社区治理和长期 PR 协作
