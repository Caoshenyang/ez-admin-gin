# 路线图

`EZ Admin Gin` 的目标不是一次性 Demo，而是一套面向 Java 转 Go 工程师、能长期复用并持续扩展的后台管理系统底座。

> 当前稳定版本：**v1.1.0** | 最后验证日期：2026-04-30

## 阶段规划

| 阶段 | 目标 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| 项目初始化 | 建立可运行的仓库骨架 | `server`、`admin`、`docs`、`deploy`、`scripts` 职责清晰 | ✅ 已完成 |
| 后端基础设施 | 后端具备真实项目基础能力 | 配置、日志、数据库、Redis、响应格式和健康检查可运行 | ✅ 已完成 |
| 认证与权限 | 完成后台系统核心安全能力 | 登录、JWT、角色、权限、Casbin 控制链路可验证 | ✅ 已完成 |
| 通用系统模块 | 补齐后台底座常用能力 | 用户、角色、菜单、配置、文件、日志可管理 | ✅ 已完成 |
| 前端管理台 | 让系统可视化可操作 | 登录页、布局、动态菜单和基础管理页面可使用 | ✅ 已完成 |
| 业务模块规范 | 定义以后小项目如何接入 | 至少有一个示例模块能证明结构可复用 | ✅ 已完成 |
| 部署与复用 | 支持快速上线和复制 | Docker Compose、Nginx、初始化数据和部署文档齐备 | ✅ 已完成 |

## 当前下一步

`v2` 主线已经不再是“开始升级”，而是进入“收口教程与补齐交付能力”的阶段。

### 当前已收稳的主线

- `bootstrap / platform / module` 后端骨架已经定稿
- 核心系统模块已经按最终结构收敛到 `module/system` 与 `module/iam/*`
- 教程主线已经扩展为企业级完整版 9 章，第 3-9 章的章节边界与正文主题已经全部对齐
- 部署、排障、回滚、长期运维与项目复用已经形成第 8 章闭环
- 快速启动、项目结构、企业级架构升级这几张总入口页也已经同步到当前阶段口径
- 站点侧边栏和文档基线清单也已经切到 canonical 主线，不再继续把旧章节页混进教程导航

### 当前真正剩下的重点

- `Phase 4` 已经完成数据字典、账户中心、附件中心这些首批常用能力，非 `system` 分组业务模块的接入规范也已经沉淀到教程与参考页；下一步不再是补结构，而是按这套骨架继续扩可复用能力谱系
- 第 5 章数据权限主线已经收成完整闭环，不再继续作为“章节边界未定”的进行中项
- 继续扩展关键链路自动化测试基线：当前已经接通 `setup/init`、登录成功/失败、`/auth/me`、一个 RBAC 拒绝场景、一个数据权限过滤场景，以及数据字典、附件中心等模块成功路径；组织树的 `dept_and_children / self` 数据范围和 embed 迁移资产同步性也已进入自动化测试，真实数据库迁移烟雾验证的测试入口和脚本也已经补齐，下一步是在允许 Docker 的环境里完成 PostgreSQL / MySQL 双库实测

### 这轮升级的交付目标

- 教程读者可以按 9 章主线直接搭出最终版后台底座
- 新模块接入、部署复用和排障手册可以直接服务后续小项目交付
- 项目质量不再只靠“本地能跑”，而是开始具备可复验的最小测试基线
