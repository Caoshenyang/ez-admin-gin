# 从零搭建教程

这条主线会从空仓库开始，一步步搭出 `EZ Admin Gin` 的当前稳定形态。目标不是做一个只能演示的后台 Demo，而是直接完成一套可扩展、可复用、可部署的后台底座。

当前稳定版本：**v1.1.0**

::: tip 🎯 怎么读这套教程
第一次阅读，建议直接按第 1 章到第 8 章顺序推进。每一章都会同时回答三件事：这章要做成什么、为什么这样设计、执行后应该看到什么。
:::

## 阅读建议

- **Java 转 Go 工程师**：建议按 1 → 8 顺序走，重点关注工程结构、权限链路和数据权限章节
- **已有 Go 经验的开发者**：可以先读第 3-5 章，再回头补前面的仓库与基础设施
- **只想看新增模块怎么接进来**：直接看第 6 章的模块接入相关页面
- **只想看部署和复用**：直接看第 8 章
